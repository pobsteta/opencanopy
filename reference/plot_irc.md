# Visualiser une ortho IRC en fausses couleurs

Affichage IRC classique : PIR en rouge, Rouge en vert, Vert en bleu La
végétation active apparaît en rouge vif.

## Usage

``` r
plot_irc(irc_raster, title = "Ortho IRC IGN (0.20m)")
```

## Arguments

- irc_raster:

  SpatRaster IRC IGN (PIR, Rouge, Vert)

- title:

  Titre
