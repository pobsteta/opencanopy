# Lister les fichiers du dataset sur Hugging Face

Lister les fichiers du dataset sur Hugging Face

## Usage

``` r
hf_list_files(repo_id, path = "", token = "")
```

## Arguments

- repo_id:

  Identifiant du dépôt (ex: "AI4Forest/Open-Canopy")

- path:

  Chemin dans le dépôt (ex: "" pour la racine)

- token:

  Token Hugging Face (optionnel)

## Value

data.frame avec les informations des fichiers
