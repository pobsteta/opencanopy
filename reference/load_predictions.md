# Charger les prédictions

Charger les prédictions

## Usage

``` r
load_predictions(prediction_path)
```

## Arguments

- prediction_path:

  Chemin d'un fichier de prédiction, ou d'un répertoire dont les .tif
  seront tous chargés

## Value

SpatRaster, ou liste de SpatRaster si `prediction_path` est un dossier
