# Scanner un répertoire pour trouver les ortho IGN

Scanner un répertoire pour trouver les ortho IGN

## Usage

``` r
scan_ign_files(dir_path = DATA_DIR_IGN, recursive = TRUE)
```

## Arguments

- dir_path:

  Répertoire à scanner

- recursive:

  Recherche récursive

## Value

data.frame avec les fichiers trouvés et leur type
