# Comparaison SPOT (1.5m) vs IGN (0.20m) sur la même zone

Comparaison SPOT (1.5m) vs IGN (0.20m) sur la même zone

## Usage

``` r
plot_resolution_comparison(spot_raster, ign_raster, tile_name = "")
```

## Arguments

- spot_raster:

  SpatRaster SPOT

- ign_raster:

  SpatRaster ortho IGN RVB

- tile_name:

  Nom de la tuile
