# Calculer le NDRE (Normalized Difference Red Edge) approximé

Approximation basée sur la différence PIR - Vert normalisée. Utile pour
différencier les espèces et l'état de santé.

## Usage

``` r
compute_savi(irc_raster, L = 0.5)
```

## Arguments

- irc_raster:

  SpatRaster IRC IGN

## Value

SpatRaster
