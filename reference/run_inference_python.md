# Exécuter l'inférence sur une tuile via Python

Exécuter l'inférence sur une tuile via Python

## Usage

``` r
run_inference_python(tile_path, model_path, output_path = NULL)
```

## Arguments

- tile_path:

  Chemin du fichier raster de la tuile

- model_path:

  Chemin du modèle .ckpt

- output_path:

  Chemin de sortie

## Value

Chemin du fichier de prédiction
