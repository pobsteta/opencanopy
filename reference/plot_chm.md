# Visualiser le CHM

Visualiser le CHM

## Usage

``` r
plot_chm(chm_raster, title = "Canopy Height Model (m)", col_palette = NULL)
```

## Arguments

- chm_raster:

  SpatRaster du CHM

- title:

  Titre du graphique

- col_palette:

  Vecteur de couleurs ; `NULL` pour la palette par défaut

## Value

Invisible `NULL`, appelée pour son effet de bord (tracé)
