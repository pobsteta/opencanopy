# Comparaison multi-panneaux : IGN RVB + IRC + NDVI + CHM

Comparaison multi-panneaux : IGN RVB + IRC + NDVI + CHM

## Usage

``` r
plot_ign_full_comparison(
  rvb_raster,
  irc_raster,
  chm_raster = NULL,
  tile_name = ""
)
```

## Arguments

- rvb_raster:

  SpatRaster ortho RVB IGN

- irc_raster:

  SpatRaster ortho IRC IGN

- chm_raster:

  SpatRaster CHM (optionnel)

- tile_name:

  Nom de la tuile
