# Croiser NDVI (IGN IRC) et CHM pour caractériser la végétation

Croiser NDVI (IGN IRC) et CHM pour caractériser la végétation

## Usage

``` r
cross_ndvi_chm(ndvi_raster, chm_raster)
```

## Arguments

- ndvi_raster:

  SpatRaster NDVI (depuis ortho IRC IGN)

- chm_raster:

  SpatRaster CHM LiDAR

## Value

SpatRaster avec classes croisées
